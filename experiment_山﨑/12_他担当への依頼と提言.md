# 他担当への依頼と提言 (Requests to Other Members)

担当D の設計を進めるうえで，他の担当と相談・依頼が必要なことをまとめる．型（`src/core/`）を変えるものは，**小さい専用の PR** にして全員に知らせる（SPEC_01）．

## 担当C（lobby/） (Lobby)

### CalibrationProfile の項目案 (Calibration Fields)

今の型は `yawOffset`・`stepPeakThreshold`・`standingBaseline`・`crouchThreshold` の 4 つ．判定の方式（[04](04_足踏み.md)・[05](05_しゃがみ_立ち上がり_しゃがみ歩き.md)）に合わせて，次の形にする案．

| 項目 | 内容 | 取る手順 |
| --- | --- | --- |
| `yawOffset` | 正面のヨー角（今のまま） | 正面を数秒見る |
| `restNoise` | 静止時の上下の加速度のばらつき（しきい値の基準） | 立った姿勢を数秒 |
| `stepPeakStanding` | 立って足踏みした時の山の大きさ（中央値） | 立って足踏みを数歩 |
| `stepPeakCrouching` | しゃがみ歩きの時の山の大きさ | **しゃがみ歩きを数歩（手順に足す）** |
| `stepInterval` | 足踏みの間隔（中央値） | 立って足踏みを数歩 |
| `crouchDepth` | しゃがんだ時に沈んだ量（m） | しゃがんだ姿勢を数秒（しゃがむ動作の積分から求める） |
| `crouchDuration` | しゃがむ動作にかかった時間 | 同上 |

- 項目の意味は担当D が決め，取る流れと UI は担当C が決める（SPEC「キャリブレーションとの分担」）
- 手順に「しゃがみ歩きを数歩」を足してほしい．時間が無ければ，`stepPeakStanding` から一定の割合で見積もる既定値を使う
- 時間切れの時の既定値は，担当D が記録から決めて渡す

## 担当B（scenes/） (Scenes)

| 依頼 | 理由 |
| --- | --- |
| 手と物が触れた判定にヒステリシスを付ける（触れたとみなす距離＜離れたとみなす距離．例: 5 cm と 8 cm） | 境目で触れた・離れたが何度も切り替わるのを防ぐ．E ② のように続けてボタンを押す場面で特に要る |
| つかむ物（テーブルの脚・手すり）とボタンを，**正面を向いた時に背面カメラの画角に入る高さと位置**に置く | 手は画角の中でしか判定できない．しゃがんで低い位置を握ると外れやすい（[01](01_シナリオから見た入力の要件.md)） |
| 当たり判定を見た目より大きめにする | 奥行きの見積もりに数 cm の誤差がある（[07](07_ハンドトラッキングと手の動作.md)） |
| 危険な物（ドアコック・扉）の当たり判定は小さめ，または「指を差している・握っている時だけ」有効にする | 触っていないのに危険と記録されるのを防ぐ |
| ボタンは「指を差す形の時の人差し指の先」で判定する | 手のひら全体で判定すると，隣のボタンまで押してしまう |
| 目の高さの切り替えはバネで約 0.3 秒かけて動かす | 瞬間的に変えると酔う |

- `HandState` の拡張（`indexTip`・`pinch`・`pointing`）を一緒に決めたい（[07](07_ハンドトラッキングと手の動作.md)）

## scenario（担当未定） (Scenario Engine)

| 依頼 | 理由 |
| --- | --- |
| 「見回した」の条件（`lookAround`）を `Condition` に足すか，scenes/ の `signal` で表すかを決める．条件にする場合は `ScenarioInput` に頭のヨーを足す | H1・T2・E1・E2 で「見回してから出る」を判定するため（[03](03_頭の向きと見回し.md)） |
| 危険な行動の `checks` には長めの `holdSeconds` を付ける（例: 立ち上がりは 1 秒以上続いた時だけ） | 一瞬の誤判定で危険な行動が記録されるのを防ぐ |

## render/（担当未定） (Rendering)

| 依頼 | 理由 |
| --- | --- |
| 描画の直前に，最新の頭の向きを `input/` から読み直してカメラに反映する | 入力の取得から描画までの数 ms の遅れを消す（[03](03_頭の向きと見回し.md)） |
| fps の低下を `input/` に知らせる（または `input/` が読める形で出す） | ハンドトラッキングの頻度を負荷に応じて下げるため（[07](07_ハンドトラッキングと手の動作.md)） |

## 担当A（recording/） (Recording)

- 「録画を一時ストレージに保存」の案は，SPEC の「端末のメモリ上だけに持つ」と食い違う．どちらにするかを相談したい
- 録画・カメラ・`HandLandmarker` を同時に動かすと iPhone が熱を持ちやすい．録画あり・なしでの fps とハンドトラッキングの頻度を一緒に測りたい
