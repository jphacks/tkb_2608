# 安定性とフェイルセーフ (Stability & Fail-Safe)

ゴーグルを付けた体験者は画面に触れられず，何かが壊れても自分で直せない．壊れた時にどう振る舞うかを先に決めておく．

## 原則 (Principles)

1. **迷ったら止まる**: 歩いているか分からない時は `walking: false` にする．勝手に進むほうが，進まないより体験を壊す
2. **姿勢は保つ**: 姿勢が分からない時は直前の姿勢のままにする（今の型の「しゃがみの途中は直前の状態を保つ」と同じ）
3. **危険な行動は確信がある時だけ**: 立ち上がり・危険な物への接触など，危険な行動につながる判定は強い証拠がある時だけ出す（[01](01_シナリオから見た入力の要件.md)）
4. **何があっても `PlayerInput` を返す**: 例外を `app/` に投げない．異常な値は直前の値か既定値（`IDLE_PLAYER_INPUT`）に置き換える
5. **壊れたら自然に戻る**: 異常から抜けたら，フィルタを初期化して数百 ms で元の判定に戻る．再起動を求めない

## 失敗のしかたと対策 (Failure Modes)

| 起きること | 気付き方 | 対策 |
| --- | --- | --- |
| センサーの値が途切れる | 最後のサンプルから 0.3 秒以上届かない | `walking: false` にする．頭の向きは最後の値のまま．再び届いたらフィルタを初期化する |
| タブが裏に回る・画面が消える | `visibilitychange` | 戻った時にすべての状態を初期化する（`dt` が数秒〜数分に飛ぶため） |
| `dt` が飛ぶ・戻る | サンプルの間隔が 0 以下か 0.2 秒を超える | そのサンプルでは積分しない．間隔が大きい時はフィルタを初期化する |
| `NaN`・`null` が来る | `Number.isFinite` で確かめる | そのサンプルを捨てる．Android の一部では `acceleration` が `null` になるため，`accelerationIncludingGravity` から求める |
| 端末の向きが反転する | `screen.orientation` の `change` | 向きの計算を切り替え，正面リセットをやり直すよう通知する |
| 熱で遅くなる | fps の低下・フレームの間隔の伸び | ハンドトラッキングの頻度を下げる（[07](07_ハンドトラッキングと手の動作.md)）．判定は落とさない |
| カメラが拒否される・止まる | `getUserMedia` の失敗・映像の `ended` | 両手を `UNTRACKED_HAND` にする．扱いは担当C が決める（SPEC「未決事項」） |
| `HandLandmarker` の読み込みに失敗する | 初期化の例外 | 手なしで体験を続ける．歩き・しゃがみには影響させない |
| Worker が落ちる | `error` イベント・一定時間結果が来ない | Worker を作り直す．2 回失敗したらメインスレッドの非同期方式に切り替える |
| 学習モデルの読み込みに失敗する | 例外 | 信号処理だけで続ける（モデルは足すもの） |
| キャリブレーションが無い・値が異常 | `Session.calibration` が `null`・範囲外 | 既定値で判定する．既定値は記録から決めた「多くの人で動く値」 |

## 酔いを防ぐ UX (Motion Sickness Prevention)

| 原則 | 方法 |
| --- | --- |
| 頭の向きは遅らせない | 平滑化はほぼしない．描画の直前に読み，先読みする（[03](03_頭の向きと見回し.md)） |
| 移動の速さを急に変えない | 加速度の上限付きのバネとダンパー（[04](04_足踏み.md)） |
| 視点の高さを瞬間的に変えない | 約 0.3 秒かけて動かす（[05](05_しゃがみ_立ち上がり_しゃがみ歩き.md)） |
| 勝手に動かさない | 迷ったら止まる．1 歩目の仮の動き出しは低速 |
| 視点を揺らさない | PLAN_04 のとおり，地震の揺れはカメラを揺らさず，物と音で表す（scenes/・audio/） |

## 人・端末の違いへの強さ (Robustness to People & Devices)

- しきい値は絶対の値で持たず，**キャリブレーションの値と静止時のノイズの大きさに対する比**で持つ．背の高さ・動きの大きさ・端末のセンサーの違いを吸収する
- 静止時のノイズの大きさは，体験中も止まっている間に少しずつ更新する（ゴーグルのずれ・端末の温度による変化を追う）
- 端末ごとの違い（センサーの周期・カメラの画角）は，`dt` に合わせた係数と端末ごとの表で吸収する

## Day 1 の実機で確かめること (To Verify on Device)

- [ ] 体験中にホーム画面に戻って戻った時，勝手に歩き出さない
- [ ] カメラを手で覆う・許可を拒否した時も，歩き・しゃがみが動き続ける
- [ ] ゴーグルを左右反対に入れ直した時に，向きが正しく直る
