# 動きの記録の取り方 (How to Record Labeled Motion Data)

足踏み・しゃがみの判定のしきい値を決め直すため，ゴーグルに入れたスマホで「正解（ラベル）付きの動きの記録」を取る手順をまとめる．
1 人約 5 分．画面と音声の案内に従って動くだけで，案内した時刻からラベルが自動で付く．

- 関連 Issue: #48（しきい値の決め直し）・#49（UCI HAR の切り分け）．同じ記録を両方で使う
- 背景: `experiment_山﨑/10_デバッグ環境と動きの記録.md`・`11_検証計画.md`

## お願いしたいこと (What We Need)

- **できるだけ多くの人に 1 回ずつ**取ってほしい（目標は 3 人以上）．判定は人によって変わりやすいため，背の高さ・足踏みの強さ・頷き方の違う人の記録が欲しい
- 見回し・頷きは**体験中にやりそうな速さ**で行う．少し速めの動きも混ぜてよい（誤検出が起きる場面を集めたい）
- 足踏みは普段どおりでよい．弱めに踏む人の記録も欲しい

## 用意するもの (Requirements)

- PC: Dev Container を開いた状態（[ENV_02](../02_ENV/ENV_02_環境構築手順.md)）
- スマホ（iPhone で確認済み）と簡易 VR ゴーグル
- 周りに 1 m 四方ほどの空き（しゃがむ・足踏みをするため）

## 手順 (Procedure)

### PC で開発サーバーとトンネルを起動する

VS Code のターミナルを 2 つ開き，それぞれで実行する．開発サーバーは記録用の `npm run dev:record` を使う（`npm run dev` が動いていれば先に止める）．

```bash
npm run dev:record
```

```bash
npm run tunnel -- /src/input/dev/protocol.html
```

- ※ `npm run dev` のままだと，誰か（Claude を含む）が `src/` を編集するたびに記録中のページが再読み込みされ，開始画面に戻って記録が途切れる．`npm run dev:record` はこれを防ぐ
- ※ `npm run tunnel` は外から接続できる経路を開くため，Claude Code の auto mode では止められる．人間が実行する
- QR コードが表示されたら，スマホで読み取る．センサーは HTTPS でないと使えないため，スマホでは必ずトンネルの URL から開く

### スマホで記録する

1. `protocol.html` が開いたら「開始」をタップし，センサーの使用を許可する
2. 開始から時刻 0 までの待ち時間の間に，スマホをゴーグルに入れて装着する
3. 音声と表示の案内に従って動く．区間ごとに 6 秒の準備（説明と 3・2・1 の合図）がある

| 順番 | 区間 | 長さ | やること |
| --- | --- | --- | --- |
| 1 | 静止 | 30 秒 | 立ったまま動かない |
| 2 | 見回し | 30 秒 | 立ったまま，ゆっくり周りを見回す |
| 3 | 頷き | 15 秒 | 立ったまま頷く |
| 4 | 足踏み | 15 秒 × 3 回 | その場で足踏みする |
| 5 | しゃがむ・立つ | 40 秒 | 合図の音に合わせて 10 回くり返す（低い音でしゃがむ，高い音で立つ） |
| 6 | しゃがみ歩き | 15 秒 × 2 回 | しゃがんだまま，その場で足踏みする |
| 7 | しゃがんで静止 | 30 秒 | しゃがんだまま動かない |

4. 最後の区間が終われば完了．ゴーグルを外してよい

### 記録が保存されたか確かめる

記録は 2 秒ごとに PC へ送られ，`logs/input/<日時>_<セッション ID>.jsonl` に保存される（`logs/` は Git の管理外）．
終わったら，PC で新しいファイルができていることを確かめる．

```bash
ls -lt logs/input | head -3
```

## 注意点 (Notes)

- **途中で画面を再読み込みしない**．再読み込みすると別のファイルになり，前の記録は途中で終わったものとして扱われる．途中で再読み込みされた時は，開始画面に「前の記録は途中で再読み込みされました」と出るので，最初からやり直す
- 記録中に画面が消えないよう，スマホの自動ロックを一時的に切っておく
- 他の人の記録と区別できるよう，記録が終わったらファイル名（日時）と自分の名前を，Issue #48 にコメントするかチームのチャットに送る
- 記録には動きのセンサーの値だけが入る．カメラの映像は残さない

## 取った記録の使い方 (Using the Recordings)

記録を判定に流し直し，SPEC_01「判定の安定性」の目安と照らした結果を表で出す．

```bash
npm run replay -- --segments
```

- しきい値の組を並べて比べる: `npm run replay -- --set "名前:key=値,..."`（何度でも指定できる）
- 使い方の一覧: `npm run replay -- --help`
- ※ 記録は各自の PC の `logs/input/` にだけ残る．しきい値を決める人に記録を渡す方法はチームで決める（大きなファイルはリポジトリに入れない）
